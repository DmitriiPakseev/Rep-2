# Конвейер распознавания судебных документов

Скан → PDF, который визуально тождествен оригиналу, но в котором ищется
текст; плюс машинный отчёт проверок; плюс форма, где неподтверждённые
места разбираются **выбором мышью, без набора текста**.

## Быстрый старт

```bash
# один документ
python3 ocr2pdf.py вход.pdf out/имя.pdf --lang eng

# пакетом
printf '%s\n' /путь/док1.pdf '/путь/чат.png | rus+eng' > список.txt
python3 run_batch.py список.txt out/

# форма выбора по всем документам сразу -> out/ВЫБОР.html
# открыть в браузере, выбрать варианты, «Скачать выбранное»
python3 apply_choices.py choices.json
python3 run_batch.py список.txt out/        # тот же вызов, выбор применится
```

## Какой файл читать

| файл | зачем |
|---|---|
| `ИМЯ.pdf` | **это читать человеку.** Картинка оригинала + невидимый слой поиска |
| `ИМЯ.txt` | только для поиска и grep. **Даты, имена, подписи по нему не читать** |
| `ИМЯ_report.json` | отчёт проверок раздела 5 |
| `ВЫБОР.html` | форма выбора расшифровок |
| `ИМЯ_corrections.json` | накопленный выбор. **Актив документа, не удалять** |

`.txt` — промежуточный артефакт. Он годится, чтобы найти документ по
слову, и не годится, чтобы прочитать дату возврата.

## Что проверяется машинно

Каждый прогон печатает и пишет в `_report.json` пять проверок с
однозначным итогом — `СОВПАДАЮТ` / `РАСХОДЯТСЯ` / `НЕПРИМЕНИМО`:

| проверка | как |
|---|---|
| видимый слой тождествен оригиналу | MD5 вложенного потока (JPEG) или MD5 распакованных пикселей (PNG и другие форматы без потерь) |
| текстовый слой невидим | попиксельное сравнение рендера со слоем и без |
| текст стоит на чернилах | доля тёмных пикселей под каждым словом |
| чернила без текста | области оригинала, где текст есть, а слов в слое нет |
| строки не смешиваются | токен из одной строки таблицы не попал на строку другой |

Сравнение рендеров **не** используется для доказательства
тождественности: оно пропускает пережатие. Только хеш.

Про JPEG и PNG: JPEG вкладывается `img2pdf` байт в байт и обязан совпасть
побайтово. Для форматов без потерь `img2pdf` законно меняет контейнер на
Flate, поэтому сверяются распакованные пиксели. Способ пишется в отчёт —
он не подразумевается.

## Рукописное: почему выбор, а не автоподстановка

Измеренное на приложенных образцах, режим по умолчанию:

| поле | что прочёл OCR | верно |
|---|---|---|
| `Dated:` | `July 20, 2926` | `2026` |
| `Index No.:` | `LT-396107-26` | `LT-306107-26` |
| `My commission expires:` | `92/28/2029` | `02/28/2029` |
| `Print Name:` | `PAKSEEFV` | `PAKSEEV` |

Все четыре прошли с уверенностью выше 90. Метрика уверенности почерк не
видит — на это полагаться нельзя.

Поэтому неподтверждённое **не попадает в текст само**. Оно попадает в
форму выбора: вырезка оригинала крупно, под ней варианты, полученные
разными режимами и разной предобработкой той же вырезки. В измерениях
верное чтение оказывалось среди вариантов во всех проверенных критичных
полях, обычно первым.

Что делает место неподтверждённым:

1. **критичное поле бланка** (`Dated`, `Index No`, `Part`, `Room`,
   `Sworn`, `Notary`, `Signature`, `o'clock`…) — на измерениях это
   единственный признак, который сработал на всех четырёх ошибках выше;
2. слабая уверенность — несколько слабых слов подряд либо одно провальное;
3. расхождение двух проходов — признак слабый, см. «Честные ограничения».

## Накопление выбора

`ИМЯ_corrections.json` дописывается, а не перезаписывается; перед
изменением делается `.bak`. Ранее собранные варианты переносятся между
прогонами, поэтому быстрый прогон `--no-candidates` не стирает уже
проделанную работу. Повторный прогон применяет прежний выбор и не
задваивает его.

## Честные ограничения

* **Настоящего движка для рукописного здесь нет.** `huggingface.co`
  закрыт политикой сети этого окружения (403 на CONNECT), поэтому TrOCR
  недоступен. Варианты собираются режимами tesseract по изолированной
  вырезке. Это заметно лучше, чем распознавание в контексте страницы, но
  это не специализированный движок.
* **Два прохода — не два независимых движка.** `--psm 6` и `--psm 11` —
  один и тот же tesseract, и ошибается он в обоих режимах одинаково: на
  образцах сходство проходов 0,92–1,0 даже там, где оба прочли неверно.
  Второй проход оставлен как страховка на шумных сканах, но считать его
  работающим механизмом нельзя.
* **Настоящее расхождение видно уровнем ниже** — между вариантами по
  вырезке, где согласие падает до 0,36–0,68. Именно поэтому основная
  защита — выбор человеком, а не автоматический фильтр.
* **`read_handwriting.py` не проверен на живом API**: в этом окружении нет
  `ANTHROPIC_API_KEY`. Сам `api.anthropic.com` доступен. Скрипт добавляет
  ответ модели **как вариант**, ничего не применяя.
* **Растрированные страницы.** Если страница PDF содержит не одну
  картинку, она растрируется, и побайтовая тождественность не
  гарантируется. Такие страницы помечаются в отчёте как `НЕПРИМЕНИМО`
  поимённо, а не замалчиваются.

## Проверка работоспособности

```bash
python3 make_fixtures.py     # образцы всех четырёх форматов входа
python3 selftest.py          # критерии приёмки раздела 9
```

`selftest.py` проверяет 11 утверждений, включая эталоны:
строка DHCR `2014-D | RS | 01/02/2015 | 530.78 | 624.78 | FUEL SURC |
09/01/2014` собирается одной строкой, 11 лет `*REG NOT FOUND*` на месте,
колонка `PREFER. RENT` за 2014 пуста (0,00 % чернил против 5,17 % у
заполненной), кириллица извлекается, чужой текстовый слой отбрасывается.

## Состав

| файл | назначение |
|---|---|
| `ocr2pdf.py` | конвейер: вход → PDF + отчёт + список мест на выбор |
| `textlayer.py` | невидимый текстовый слой, применение выбора |
| `verify.py` | проверки раздела 5 |
| `engines.py` | распознавание, сбор вариантов |
| `make_review.py` | HTML-форма выбора (одна или несколько документов) |
| `apply_choices.py` | раскладывает выбор из общей формы по документам |
| `read_handwriting.py` | необязательно: модель как ещё один источник вариантов |
| `run_batch.py` | пакетный прогон + общая форма |
| `make_fixtures.py` | образцы четырёх форматов входа |
| `selftest.py` | критерии приёмки |
